Set up

This page writes your log into the private life-log-data repo. It needs a GitHub token with access to that repo and nothing else.

  1. Open github.com token settings
  2. Resource owner MKothen, repository access Only select repositories → life-log-data
  3. Repository permissions → Contents: Read and write
  4. Expiry 1 year. Generate, copy, paste below.

Stored only in this browser. Save a copy in your password manager — iOS can clear site storage after a week of not opening the page.
